# Agent Instructions

## Reference Repository

The repository located at `references/shared/`
is the approved engineering reference.

Before implementing a feature:

1. Review the reference repository's AGENTS.md.
2. Review applicable architecture documentation.
3. Identify existing implementation patterns.
4. Evaluate reusable components.
5. Follow applicable security and coding standards.

## Repository Boundaries

- Treat references/shared/ as read-only.
- All application changes must occur in the
  primary repository.
- Do not commit changes to the reference repository.
- Do not update the submodule version without approval.

## Implementation

When proposing or implementing a solution:

- Identify the reference files consulted.
- Explain deviations from established patterns.
- Document architectural decisions.
- Run applicable tests before completing the task.
